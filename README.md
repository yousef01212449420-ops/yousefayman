# Yousef Ayman — Personal Links

صفحة شخصية بسيطة وعصرية بأسلوب زجاجي مستوحى من واجهات iPhone، جاهزة للنشر على GitHub Pages.

## التشغيل محلياً

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل أي خادم ملفات محلي داخل المجلد.

## الرفع على GitHub

1. أنشئ Repository جديداً على GitHub.
2. ارفع `index.html` و`style.css` ومجلد `assets`.
3. من **Settings → Pages** اختر الفرع `main` والمجلد `/root`.
4. احفظ الإعدادات وسيظهر الموقع على رابط GitHub Pages الخاص بك.

> تم حفظ صورة البروفايل داخل `assets/profile.jpg` حتى يعمل الموقع بدون الاعتماد على رابط خارجي للصورة.
